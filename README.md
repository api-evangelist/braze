Braze is a leading customer engagement platform providing REST APIs for managing user profiles, orchestrating multi-channel messaging campaigns, and exporting analytics. The platform supports email, SMS, push notifications, in-app messages, and content cards across mobile and web channels. Braze uses Bearer token authentication with region-specific REST endpoints and offers extensive webhook and Canvas automation capabilities for lifecycle marketing.

## APIs

### Braze REST API

The Braze REST API enables server-side operations including creating and updating user profiles, triggering campaigns and Canvases, sending transactional messages, managing product catalogs, controlling subscription groups, and exporting campaign analytics and user data. Region-specific base URLs serve US, EU, AU, ID, and JP instances with Bearer token auth.

- **Human URL:** [https://www.braze.com/docs/api/basics/](https://www.braze.com/docs/api/basics/)
